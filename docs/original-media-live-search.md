# Original media live search checks

Run date: 2026-11-11

Each search site was opened in an isolated Chromium profile with the current built extension. Where a result image was available, the runner located and clicked it in the live page DOM, then invoked the extension’s Alt+right-click flow. A temporary local fake desktop receiver captured the extension upload bytes. Sharp decoded each successful upload and confirmed format, dimensions, and byte length. No asset was imported into a real Serpent library.

Three sites produced verified public image downloads. Google and DuckDuckGo showed human-verification interstitials; Yandex showed an access gate. Those barriers were recorded without being bypassed. Bing opened a detail overlay, but its overlay iframe/mask intercepted the extension right-click after the result click, so no upload was recorded.

“Page original extraction” below is evidence-based: a distinct original URL counts only if the uploaded source URL matches a page-declared image candidate. “Download” means the real extension fetched and uploaded decodable public image bytes to the isolated receiver. A successful upload does not mean the image entered a real Serpent library. For the three downloaded samples, the final source matched the displayed preview or its explicitly resized CDN variant; this does not establish whether a separate original was unavailable or simply not selected by the page resolver.
