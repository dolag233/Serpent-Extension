# 原图与原视频来源研究

**研究日期：2026-11-10。** 这是对公开源码的静态阅读，没有访问站点页面、请求媒体、运行兼容性测试或下载文件。因此下列均为**候选来源和待验证限制**，不是已验证兼容性，也不保证 CDN 会返回原始字节。

## 证据范围

为便于复核，引用固定到研究时的上游提交：

- [Hover Zoom+（MIT）源码快照](https://github.com/extesy/hoverzoom/tree/a2d82a9a76200f605b62af0a6299619eca4f4e42)，重点看逐站插件。它演示如何把页面里同一结果卡片的缩略图与更大媒体 URL 关联起来；其规则也会随站点改版而失效。
- [gallery-dl（GPL-2.0）源码快照](https://github.com/mikf/gallery-dl/tree/811d917b4973ae4f556a760e289784fd4714e2f1)及[默认站点配置](https://github.com/mikf/gallery-dl/blob/811d917b4973ae4f556a760e289784fd4714e2f1/docs/gallery-dl.conf)。配置明确列出 Behance、ArtStation、Pinterest、Instagram、Pixiv、Twitter、Weibo 等的图片/视频选项。它是网络提取器，不等同于浏览器扩展中的 DOM 解析器。
- [yt-dlp（Unlicense）源码快照](https://github.com/yt-dlp/yt-dlp/tree/412e7f0a4b0588fe884a02b344ac66a06538475b)，用于核对小红书、微博、Instagram、X 的页面解析和视频格式字段。
- [Image Max URL（Apache-2.0）源码快照](https://github.com/qsniyg/maxurl/tree/f6f0778f4ce673845139fab26cca994f233e02ec)。把它当作逐站规则库参考；本报告不据此推定任何一个站点已兼容，也不把它描述为可直接调用的 npm API。
- [RSSHub 站酷用户路由](https://github.com/DIYgod/RSSHub/blob/546505738f2e9e6b1a138e3a900ee7acf2e159a2/lib/routes/zcool/user.ts)、[详情数据转接](https://github.com/DIYgod/RSSHub/blob/546505738f2e9e6b1a138e3a900ee7acf2e159a2/lib/routes/zcool/utils.ts)与[作品模板](https://github.com/DIYgod/RSSHub/blob/546505738f2e9e6b1a138e3a900ee7acf2e159a2/lib/routes/zcool/templates/work.tsx)给出页面数据入口和大图字段，但不证明大图就是上传原文件。

下表中的“原图”均表示更大尺寸或原始字段的**候选**。源 URL 可能指向站点缩略图、代理图、带签名的 CDN 对象或需要访问权限的媒体。站点搜索结果最多支持使用结果中返回的直链，以及在保持结果 ID 关联的前提下有限跟进详情页；不能承诺穿过任意来源站点继续验证。

## 通用兜底建议

1. **先保留命中元素本身的来源。** 图片候选按当前图片及 `srcset` 的最大声明尺寸、同节点的 `data-*` 原图字段、同一结果卡片里与内容 ID 关联的数据排序；CSS 背景可作为图片候选。不要把“整个页面最大图片”当作当前指向内容。
2. **只做有证据的 URL 变换。** 每条规则要限定站点、主机、路径结构和媒体 ID；保留未知查询参数，特别是签名/鉴权参数。将转换结果作为候选逐个尝试；失败时回退到原链接，不把改写 URL 直接标为原图。
3. **详情页跟进要有限且保留关联。** 搜索结果只使用返回的直链；可选地打开/解析同一结果的详情页一次，并只接受仍能匹配原结果 ID、作品 ID、帖子 ID 或图像序号的媒体。无法确定关联时，返回原候选或说明未取得原图。
4. **视频要以当前卡片为边界。** 优先 `video.currentSrc`、匹配的 `<source>` 和同媒体对象的播放格式；若播放器只暴露 `blob:`，只用可与该播放器关联的网络来源，不要在全页请求中按扩展名或大小盲选。识别 MP4/WebM 与 HLS/DASH；清单不等于完整视频文件。
5. **报告获取结果而非推断兼容。** 请求失败、签名过期、需登录、验证码、Referer 限制或格式不受支持时，应保留失败状态和候选 URL，不声称“已验证原图”。任何要承诺支持的站点仍需用不含个人凭据的公开样本做定向验证。
