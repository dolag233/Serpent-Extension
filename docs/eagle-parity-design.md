# 扩展采集能力（对齐 Eagle 浏览器扩展）

保存仍走现有路径：浏览器下载后上传到本机 Serpent，目标由「保存到文件夹 / 保存到合集」决定。合集模式继续是先进入资源库根目录，再加入所选合集。

桌面端 `save-upload` 只接受图片和视频。纯网址收藏没有对应接口，本轮用整页截图代替「留下这个页面」；截图的来源页地址记在现有的页面 URL 字段里。

## 批量收藏

入口：工具栏面板「批量收藏此页」，以及建议快捷键 `Alt+1`。

内容脚本扫描当前文档里的 `img`、`video`、`picture`，以及带内联背景图的元素。同一保存地址只保留一条。扩展自己的界面不计入。

面板里用缩略图网格勾选。支持全选、按最短边过滤、按格式多选。筛选条件记在 `storage.sync`，下次打开沿用。尺寸未知的图（尚未解码、宽高为 0）不被尺寸条件排除。

「穿透保存」新用户默认开启，批量保存优先使用识别出的原图或最高质量视频；没有可用版本时回退到当前预览。设置在面板、选项页和其他保存入口间共享，用户可关闭并保留选择。预览仍用页面上已经显示的图。

「监测新媒体」打开后继续滚动或点击。`MutationObserver` 把新出现且通过筛选的图追加进网格，并默认勾选。停止监测不会自动保存。

保存目标沿用当前模式：文件夹模式可选具体文件夹，不选则交给桌面端当前文件夹；合集模式必须选一个合集。多张按顺序上传。中途失败即停止。只有最后一张沿用「显示窗口 / 跳转到文件夹」。结束时发一条汇总通知。单次最多 200 张。

## 单张补充

`Alt + 右键` 在捕获阶段拦截，只在指针下有图片或视频时生效，用来对付禁用右键的页面。保存目标与右键菜单相同：文件夹模式用当前选中项或桌面端当前文件夹；合集模式若没有选中的合集，提示先选择合集。普通右键不拦截。

## 截图

入口在工具栏面板。建议快捷键：`Alt+2` 区域，`Alt+3` 可见区域，`Alt+4` 整页。截取元件只有按钮，没有默认快捷键。

- 可见区域：`tabs.captureVisibleTab`，整窗保存为 PNG。
- 区域：页面上拖出矩形，再从可见区域截图里裁切。拖动时按住 Ctrl（macOS 为 ⌘）则改用指针下的元素边界。
- 元件：移动时高亮元素，单击后裁切。元素高于一屏时按垂直分段拼接，再裁到元素左右边界。
- 整页：按视口高度滚动并拼接。只覆盖当前视口宽度。高度上限 30000 CSS 像素，超出部分不截。固定定位的页头可能在每段里重复，这是滚动拼接的已知限制。

截图期间隐藏扩展自己的浮层。产物用现有上传接口，类型为 `image/png`。

## 明确不做

- 不新增桌面端「收藏链接」接口。
- 不保证每个站点都能解析到原图；高清只使用上面三条通用规则。
- 不在批量面板里重做拖拽树。目标用面板里的下拉列表选择。
